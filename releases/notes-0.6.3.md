# PRTracker v0.6.3

## Fixes

- Onboarding can no longer trap you: there's now a Cancel button at every step (including first-run), and "Set Up PR Tracker Again…" reopens setup even when nothing is configured yet.
- When a token is under-scoped or needs SSO authorization, adding a repository now says so — "GitHub denied access to owner/repo…" — instead of the misleading "Couldn't reach GitHub."
