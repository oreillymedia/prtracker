# PRTracker v0.3.1

## What's new

- Added a search field to the top of the sidebar that filters the pull-request list by title in real time.
- Moved the repository selector to sit just above your account at the bottom of the sidebar, leaving the search field at the top.
- The detail inspector now shows "Last updated" as the first field so the most recent activity time is easier to spot at a glance.

## Fixes

- The selected pull request stays readable while you're typing in the search field (it no longer washes out when the list loses focus).
