# PRTracker v0.3.0

## What's new

- Refreshed the main window with Liquid Glass styling: the pull-request source list now uses a native sidebar with system material and an inset selection highlight, and the detail view sits on a recessed plane so the message and activity cards read as raised surfaces.
- Avatar images are now cached, so they load instantly and re-download far less often.

## Fixes

- The source list no longer hangs or staggers when moving quickly between pull requests, and an earlier keyboard-navigation freeze is resolved.

## Notes

- The menu-bar item is temporarily disabled in this build — PRTracker runs as a regular window for now.
