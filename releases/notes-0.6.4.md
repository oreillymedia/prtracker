# PRTracker v0.6.4

## What's new

- Code previews on comment threads no longer swallow the window: a hunk shows its last few lines — the ones the comment is actually attached to — with a "Show N more lines" toggle for the rest. Long lines scroll sideways instead of wrapping into a wall of text.
- Mark a whole PR done (or not) in one click: new resolve-all / unresolve-all buttons in the detail toolbar.
- Right-clicking a PR in the list now offers both "Mark all as resolved" and "Mark all as unresolved", whatever state the PR is in.
