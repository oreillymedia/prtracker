# PRTracker v0.5.0

## What's new

- **Reimagined setup.** First launch now walks you through a refined, native, stepped flow — Welcome → Connect → Repositories → Notifications — with guidance at each step. You can add several repositories at once (each is verified as you add it) and choose how each one notifies you before you finish.
- **Re-run setup any time.** A new **Set Up PR Tracker Again…** menu item reopens the flow, pre-filled with your current account and repositories, so you can add, remove, or re-tune repos without losing any data.
- **Repository shown in the detail panel.** A pull request's info panel now lists which repository it belongs to, and the merge line is more compact (`head → base`).

## Notes

- Pressing Return in the token field validates it, just like the Validate button.
- The menu-bar item remains disabled in this build — PRTracker runs as a regular window for now.
