# PRTracker v0.6.5

## Fixes

- A closed or merged pull request now says so: the detail view and the list row show a Merged / Closed / Draft badge. Previously a closed PR looked exactly like an open one everywhere but the inspector.
- Closing or merging the PR you're currently viewing shows up within about 30 seconds, instead of waiting for the next full repository sync.
- Repositories with more than 50 open pull requests no longer have their least-recently-updated PRs quietly marked as closed.
